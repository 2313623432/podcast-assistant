# 播客助手

播客助手是一个面向中文口播内容创作者的小工具：把长文案输入进去，自动调用火山引擎「豆包语音」生成 MP3，同时生成可用于剪映、视频号、抖音等剪辑流程的 SRT 字幕。

如果你只想使用软件，不需要安装 Python、ffmpeg 或任何开发环境，直接到 GitHub Releases 下载 `播客助手-单文件.exe`。

## 它能做什么

- 将长文案合成为自然口播 MP3
- 自动拆分长文本，分段合成后拼接成完整音频
- 同时导出 SRT 字幕，方便做视频字幕
- 支持单人播讲和双人对话
- 支持自定义音色 `voice_type`
- 支持调整语速、音高、音量
- 支持字幕分段长度设置，适配手机竖屏观看
- 内置 ffmpeg，单文件版 EXE 可直接运行

## 适合谁

- 做养生、知识科普、书籍拆解、课程讲解的内容创作者
- 需要批量把文案变成口播音频的人
- 需要 MP3 和 SRT 字幕一起生成的人
- 不想折腾 Python 环境、ffmpeg 配置的人

## 快速使用

1. 打开 GitHub Releases
2. 下载 `播客助手-单文件.exe`
3. 双击运行
4. 浏览器会自动打开软件页面
5. 在左侧输入火山引擎「豆包语音」的 App ID 和 Access Token
6. 粘贴文案，选择单人或双人模式
7. 点击“生成音频与字幕”
8. 下载生成好的 MP3 和 SRT

首次启动可能会慢一些，因为单文件 EXE 会把内置运行环境临时解压出来。运行时会出现一个黑色命令窗口，软件使用期间不要关闭它。

## 火山引擎凭证说明

软件需要你自己的火山引擎「豆包语音」凭证：

- `VOLCANO_TTS_APP_ID`
- `VOLCANO_TTS_ACCESS_TOKEN`

凭证可以直接在软件左侧栏手动输入。不要使用 IAM 的 AccessKey/SecretKey，也不要使用其他产品的 API Key。

## 文案格式

单人模式：直接粘贴正文即可，空行会被当作段落分隔。

双人模式：每行使用“角色名：台词”的形式。

```text
大刘：今天我们聊聊如何把长文案变成播客音频。
小芳：听起来很实用，能不能同时生成字幕？
大刘：可以，软件会同时导出 MP3 和 SRT。
```

## 开发者运行

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## 重新打包

文件夹版：

```powershell
pyinstaller --noconfirm --clean ".\播客助手.spec"
```

单文件版：

```powershell
pyinstaller --noconfirm --clean ".\播客助手-单文件.spec"
```

单文件成品位于：

```text
dist\播客助手-单文件.exe
```

## 重要提醒

- 本工具只负责文本转语音和字幕生成
- 火山引擎 TTS 调用会消耗你自己的账号额度
- 不要把真实 Token 提交到 GitHub
- 生成的音频内容请自行确认版权和平台合规要求
